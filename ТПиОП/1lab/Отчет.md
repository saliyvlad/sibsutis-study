### 3. Теоретические сведения

#### 3.1 Метод Симпсона

Метод Симпсона основан на замене подынтегральной функции на каждом участке [xᵢ₋₁, xᵢ₁] параболой, проходящей через три точки. Формула Симпсона:

$$I \approx \frac{h}{3} \left[ f(x_0) + 4\sum_{i=1,3,5...}^{n-1} f(x_i) + 2\sum_{i=2,4,6...}^{n-2} f(x_i) + f(x_n) \right]$$

где h = (b-a)/n, n — четное число разбиений.

Погрешность метода: O(h⁴), что обеспечивает высокую точность при относительно небольшом числе разбиений.

#### 3.2 Правило Рунге

Для автоматического контроля точности используется правило Рунге. Если Iₙ и I₂ₙ — приближенные значения интеграла при n и 2n разбиениях соответственно, то:

$$|I - I_{2n}| \leq \frac{|I_{2n} - I_n|}{2^p - 1}$$

где p = 4 для метода Симпсона.

Вычисление продолжается до тех пор, пока оценка погрешности не станет меньше заданной точности ε.
